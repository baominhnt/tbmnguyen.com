Credit Risk Analysis Project

Credit Risk Analysis Report - “Default Hotspots Detected”, delivers a powerful dashboard uncovering how young, leveraged, and unstable borrowers drive default risk across the US, UK, and Canada. Using Python for data cleaning and preprocessing (including engineered columns to sharpen affordability and delinquency signals), machine learning models to predict default likelihood, and SQL Server to store and manage the borrower database, the analysis highlights critical warning thresholds with loan‑to‑income above 30%, debt‑to‑income above 0.5, and credit utilization over 70%. Visualizations at the descriptive analysis stage reveal concentrated risk in high‑stress loan grades and intents like debt consolidation and medical loans, while protective factors such as prime grades, home ownership, and stable employment emerge as resilience anchors. The result is a Borrower Risk Radar that equips the system to balance fair lending with financial safety.

November, 2025

Heart Attack Predictions
Machine Learning Project

Built a predictive framework in R to assess heart disease risk using the UCI Cleveland clinical dataset. Designed a reliable data pipeline to validate 303 patient records, impute missing values, and encode categorical features for high‑quality modeling. Implemented and benchmarked multiple supervised learning algorithms—including Decision Trees, Naive Bayes, KNN, and Random Forest—to evaluate diagnostic accuracy and interpretability. Complemented this with unsupervised analysis using the Apriori algorithm to uncover non‑linear associations between symptoms and disease presence. The Decision Tree model achieved the strongest performance at 89.2% accuracy, outperforming ensemble methods on this small dataset. Final analysis identified Chest Pain Type (cp) and Major Vessel Count (ca) as the most influential predictors, offering clinically meaningful thresholds to support early intervention and improved decision‑making.
