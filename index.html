Heart Attack Predictions
Machine Learning Project

Built a predictive framework in R to assess heart disease risk using the UCI Cleveland clinical dataset. Designed a reliable data pipeline to validate 303 patient records, impute missing values, and encode categorical features for high‑quality modeling. Implemented and benchmarked multiple supervised learning algorithms—including Decision Trees, Naive Bayes, KNN, and Random Forest—to evaluate diagnostic accuracy and interpretability. Complemented this with unsupervised analysis using the Apriori algorithm to uncover non‑linear associations between symptoms and disease presence. The Decision Tree model achieved the strongest performance at 89.2% accuracy, outperforming ensemble methods on this small dataset. Final analysis identified Chest Pain Type (cp) and Major Vessel Count (ca) as the most influential predictors, offering clinically meaningful thresholds to support early intervention and improved decision‑making.
